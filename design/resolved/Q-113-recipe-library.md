# Q-113: Recipe library: tags, search, favourites, notes

## Context
Imported recipes bring tags (schema.org `recipeCategory`, `keywords`). The library needs to be findable from the meal planner.

## Question
What does the library offer?

## Options
- A. Search by title and ingredient, tag filter chips (D-105), favourites, "last planned" from the plan, a household note per recipe (suggested)
- B. A, plus per-member ratings (a base for later suggestions)
- C. Title search only

## Answer
<!-- answer below this line -->
Option B.
