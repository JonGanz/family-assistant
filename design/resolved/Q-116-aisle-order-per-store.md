# Q-116: Aisle order: one for all stores, or per store

## Question
## Context
D-115 groups the list by store, then aisle. Aisles are laid out differently in each store, so one shared aisle order may not match how a person walks a given store.

## Question
Is the aisle order shared or per store?

## Options
- A. One aisle order for every store (suggested; simple, and most households shop mainly one store)
- B. Each store has its own aisle order (and may hide aisles it does not have)
- C. Configurable: shared by default, with an optional per-store override

## Answer
<!-- answer below this line -->
B
