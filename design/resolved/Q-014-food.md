# Q-014: Meal planning & grocery details

## Question
How far ahead do you plan meals (a week? flexible)? Do you need pantry or inventory tracking, so items you already have are skipped on the grocery list? Should we group the list by store aisle, export it (AnyList, Google Keep, Todoist, Instacart), or print it? Are there dietary restrictions per member?

## Answer
<!-- answer below this line -->
Let's say.. plan any number of weeks ahead (configurable) and user can generate a list for any of the upcoming meals. No need to export to other apps at this time. List should be visible in app, and users should be able to add to it from the dashboard.
