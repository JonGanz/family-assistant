# Q-029: How children sign in

## Question
Kids see their own calendar and tasks (D-006). How do they sign in on a phone or tablet?

## Options
- A: username + simple password set by an adult; long-lived session on their device (recommended)
- B: adult pairs the kid's device once (like the dashboard), no password
- C: kids only use the dashboard for now, no personal login

## Answer
<!-- answer below this line -->
Option A
