# Q-048: What a goal looks like

## Question
Before goals are designed, their shape needs settling. Candidate features:

1. **Measures:** a count (nights read), a quantity (minutes, kilometres, money), a checklist of milestones, or a percentage entered by hand.
2. **Progress sources:** manual entry, ticked tasks ("each completed *Read* task counts 1"), or later from email (grades in M3).
3. **Cadence:** a daily or weekly target ("10 minutes a night") as well as a total ("300 minutes this month").
4. **Streaks:** consecutive days met. D-013 ruled out points and rewards; streaks are on the border.
5. **Who:** goals for children set by adults, adults' own goals (private by default?), and household goals.
6. **Display:** progress bars on the phone and an optional dashboard `goals` panel.

**Which of these should goals have?**

## Options
- A. Minimal: a count or quantity toward a total, manual progress, per member, a progress bar. No cadence, no streaks.
- B. Full: all six above, including streaks.
- C. **Configurable per goal, default: count or quantity, manual or from tasks, optional daily or weekly cadence, no streaks, adults' goals private by default, dashboard panel optional** (recommended). Streaks could be a per-goal toggle later.
- D. Something else (describe).

## Answer
<!-- answer below this line -->
Option D. We should include the measures such as a basic quantity or count. We should include some level of cadence where a goal can be scheduled as a weekly goal and resets every week on a certain date. We will allow the goals to be set for anyone configured by adults for now. Definitely show the progress bars; I think they're awesome. And let's not rule out entirely that we may add streaks and points or rewards later, but we're not going to include that at this point in time.
