# Q-104: Servings: default and scaling on the list

## Context
A recipe serves N. The plan may cook it for more or fewer people, and the grocery list should scale the quantities.

## Question
How are servings set per entry?

## Options
- A. Each entry has servings, defaulting to the recipe's; the list scales quantities by entry/recipe servings (suggested)
- B. Each entry picks who eats (members), and servings default to that count
- C. No scaling: quantities as written
- D. Configurable default per household (recipe servings / household size / a fixed number), default recipe servings

## Answer
<!-- answer below this line -->
Option A.
