# Q-010: Echo Show 15 kiosk approach

## Question
There are 3 ways to keep the dashboard on the Echo Show 15. (1) Silk browser plus a keep-alive trick, which is fragile. (2) Sideload Fully Kiosk Browser. This needs developer mode, and recent Fire OS versions block it. (3) Swap to a Fire tablet or wall tablet. Are you willing to sideload or root it, and do you want touch interaction (checking off tasks) or display only? Is voice (Alexa) in scope?

## Answer
<!-- answer below this line -->
Option 1, the keep-alive trick. No Alexa control needed.
