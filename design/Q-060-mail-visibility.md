# Q-060: Who can see which messages?

## Question
Each mail source has owner members (D-007), often shared between adults. The privacy rules so far are: adults see household data, adults' private events show as Busy (D-036), and children see their own things.

Email is more personal than calendars. Today the plan says: **adults see messages from sources they own; nobody else sees them.** Derived items (events, tasks, bills) are visible like any other event, task or bill, with the 'from email ↗' link only working for owners.

**Who should see messages?**

## Options
- A. Every adult sees every source's messages.
- B. **Owners only, configurable per source** (recommended): a source can be marked `household` (all adults see it) or stay owner-only. Children never see the message list in M3, but see the tasks and events derived for them.
- C. Like B, and children also see messages linked to them from school, daycare and activity orgs (read-only).
- D. Something else (describe).
