# Q-005: Users, login & privacy between members

## Question
Should every member have a login? Should adults be able to see each other's email-derived items? What can kids see or do (complete tasks only, view their own schedule)? Is the dashboard open to anyone with no login?

## Answer
<!-- answer below this line -->
The dashboard should not be associated to a specific user, but allow users to interact with it and set their user for the action. For the basic web/phone views, there would be a separate login per user. Kids would see their own calendar/tasks, adults would have access to all of it, but cannot update settings for other adults.
