## Work
1. **Mail mode:**
   - A `UiRadioGroup` or `UiSegmented` with "Use the AI for every message (rules as fallback)" (`llm_first`, default) and "Use rules first, AI only when unsure" (`rules_first`).
   - It is a setting with an instant apply and Undo (D-096), as the existing extract-mode control is.
   - In `llm_first`, hide the extract-mode control (it does not apply) and show the catch-up window ("Catch up on mail from the last N days", 0–365, default 30).
2. **Rules thresholds (rules_first only):** per decision point, a rules threshold slider next to the existing LLM threshold (50–99 %, saved on release with Undo, like the LLM threshold). Add the extraction fallback cutoff next to the extract mode.
3. **Backlog:**
   - Show `GET /ai/backlog` as a line under the endpoint card, for example "12 messages waiting for the AI · 3 queued". Show nothing when both are 0.
   - Refresh it when the endpoint is saved or toggled, and every 30 s while the page is open.
4. **Tests:** update the store and view tests. Update the mocked `ai-settings` shot route in `e2e/ui-shots.routes/ai.ts` so the new controls and a non-zero backlog show.
5. **Arch:** update `arch/Frontend.md` §3e and its diagram source if a shown part changes.
