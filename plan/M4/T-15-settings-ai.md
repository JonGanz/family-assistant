# T-15: Settings → AI screen: LLM endpoint, email decision stages, extraction mode, activity

You are a sub-agent implementing one task of milestone M4 (UI revamp and LLM extraction slice) of the Family Assistant project, a self-hosted family organiser with a Rust backend and a Vue 3 frontend in `apps/web`. Track B built the backend: an OpenAI-compatible LLM endpoint, an `llm` pipeline stage for email and the `/ai/*` API (T-08). Track A built the design system and migrated every view. You build the one new screen where the two tracks meet: **Settings → AI** (`/settings/ai`, adults only), on the design system and following the reference pages.

## Work
1. **`stores/ai.ts`** (Pinia, typed from `gen/` only) exposes:
   - `endpoint` (or `null` on 404 `not_configured`), `settings`, `pipeline` (four rows) and `stats`;
   - the actions `load()`, `saveEndpoint(body)`, `testEndpoint(body?)`, `loadModels()`, `saveSettings(body)`, `setStage(dp, {llm_enabled, llm_threshold})` and `loadStats(days = 7)`.
   `api_key` follows the PUT rule: absent means keep, `null` means clear, a string means set.
2. **Settings nav:** an `AI` group (or a page in the Sources and rules group, if T-13's structure suggests it; say which) with entry `ai`, icon `ai`, summary "Local language model for email". It is adult only.
3. **`SettingsAiView.vue`** is a stack of `UiCard`s (§3e):
   - **LLM endpoint:**
     - a form via `useFormDraft` with `UiSaveBar`: base URL, model, dialect (`UiSegmented`: OpenAI-compatible or Ollama native), timeout (seconds in the UI, `timeout_ms` on the wire), and the API key as a write-only field ("set / not set", Replace, Clear);
     - the **enabled** switch saves instantly with Undo (`useInstantSave`, PUT with the stored values);
     - **Test connection** (tonal button) posts the draft values to `/ai/llm-endpoint/test` and shows the latency, model found yes or no, or the error kind in plain words (`unavailable` → "Can't reach the server", `timeout`, `http`, `bad_json`, `schema`);
     - the model field is a `UiSelect` filled from `/ai/llm-endpoint/models` when that answers, or a text field with a 'Refresh list' icon button otherwise;
     - a hint line: "Run the LLM server on your home network or tailnet only; it has no password by default."
     - Before any endpoint exists, an empty state explains what this is, with a 'Set up' button that opens the form, prefilled with `http://<gpu-pc>:11434/v1` as a placeholder (not a value) and the model placeholder `qwen3:8b` (R-004).
   - **Email decisions:** a `UiList` with one row per decision point, showing a readable name ("Category", "Time-sensitive", "Which members", "Is a bill"). Each row has an LLM `UiSwitch` (instant with Undo, `PUT /ai/pipeline/{dp}`) and a threshold slider 0.50 to 0.95 shown as a percentage. The slider saves on release with Undo, and is disabled while the switch is off. While the endpoint is disabled, the card says the stage waits for the endpoint.
   - **Extraction:** `mail_extract_mode` as `UiSegmented` (Off, When rules find nothing, Always; instant with Undo) and `max_input_chars` as a small form with the Save bar.
   - **Activity (last 7 days):** read-only. Per purpose it shows calls, success share, and p50 and p95 latency; per decision point, a stacked bar of the rules, LLM and person shares (tokens and theme hues only, with a text legend), plus a refresh button. The empty state is "No AI activity yet."
4. Loading uses `UiSkeleton` per card. A load error uses `UiErrorState` with retry. A 409 or field errors appear in the Save bar and under the fields.
5. **Tests** (`views/settingsAi.test.ts`, `stores/ai.test.ts`, mocked API):
   - 404 shows the empty state;
   - Save sends `api_key` absent when untouched, `null` after Clear, and the string after Replace;
   - the enabled switch shows Undo and Undo restores;
   - Test connection renders success and `unavailable`;
   - the stage switch calls `PUT /ai/pipeline/{dp}`;
   - a child session cannot reach `/settings/ai` (guard).
6. Run `scripts/ui-shots.sh --all` with `/settings/ai` in its empty and configured states (configured needs the e2e stack; if there is no endpoint there, shoot the empty state and report it).
