# M4 ground rules

Read [`plan/_rules-common.md`](../_rules-common.md) first. These are the M4 deltas.

- **Contracts:** `plan/M4.md`, *Contracts fixed up front*, is the source of truth for names, types, routes, columns and wire formats. Track A tasks also follow the R1/R2 feedback the main session appends to their brief.
- **Two tracks, one checkout.** Track A (web) and track B (Rust) run at the same time. Web tasks never build Rust, and Rust tasks never run `pnpm install`.
- **Disk (stricter than common):**
  - Run `df -h /` before every build and stop below 6 GB free.
  - Build with `CARGO_INCREMENTAL=0` and build or test **only your own crates** (`-p`). Use `cargo check --workspace` once at the end, never `cargo build --workspace` or `--release`.
  - Add no inference runtime and no heavy client: no CUDA, `candle*`, `llama-cpp*`, `mistralrs`, `ort`, `tch` or `async-openai` (D-093). A new dependency is reported with its reason and added only as `workspace = true`. If it is missing from the root `Cargo.toml`, report it; the main session adds it.
- **SQL:** do not run `cargo sqlx prepare`. Use runtime `sqlx::query` / `query_as` for every query you add or change.
- **Real data:** the dev DB holds a real household. Never point `fa-server eval`, the `mail.llm` job or any LLM call at it. Tests use fixtures, an `axum` stub server for LLM endpoints, and a fresh container (port 55400 + task number).
- **No content in logs or tables:** prompts, mail text and LLM responses are never logged or stored. `llm_call` holds metrics only.
- **Web checks** (in `apps/web`): `corepack pnpm@9 run lint`, `typecheck`, `test`, `build`, then `corepack pnpm@9 run format`. `apps/web/src/gen/**` is regenerated by the main session only. Until then, type new DTOs locally and list the casts in your report.
- **UI rules (track A):**
  - Colours come only from theme variables, through the `--ui-*` tokens. No hex, `rgb()` or named colours in views or components (the `ui/tokens.css` mixes are the only exception).
  - Icons are imported from `ui/icons.ts` only.
  - Layouts are mobile-first: write the 360 px layout first, then widen with `min-width` queries at 600 and 840 px.
  - Touch targets are at least 48 px, focus is visible, and every icon-only button has an `aria-label`.
  - Apply changes as D-096 says: `useInstantSave` for single controls, `useFormDraft` with `UiSaveBar` for forms, and creation in `UiSheet`.
  - Keep the e2e selectors (see `plan/M4.md`, *View ownership*).
- **Screenshots for review:** track A tasks finish by running `scripts/ui-shots.sh` (once T-02 has made it) and list the PNG paths plus their open questions in the report. Use `--gallery` in wave 1, and `--all` from wave 2 on, which needs Docker for the e2e stack. If Docker is busy, say so and skip.
- **Local rustc is 1.99.1.**
