# T-12: M5 end-to-end tests

You are a sub-agent implementing one task of milestone M5 of the Family Assistant project, a self-hosted family organiser with a Rust API and a Vue PWA. M5 adds recipes, a meal plan with templates, and one living grocery list, with a kiosk Food view. Unit tests passed in earlier milestones while real flows broke, so M5 is only done when its flows pass end to end. You write fictional recipe pages, serve them from the e2e stub server, and write the API and UI specs.

## Work
1. **Fixtures** (`e2e/fixtures/recipes/`), fictional and written by you (D-035), with no real site's text or images:
   - `jsonld.html`: a schema.org Recipe JSON-LD page with an `image` URL on the stub server;
   - `microdata.html`: the same kind of recipe as microdata;
   - `plain.html`: no structured data;
   - `image.png`: generate a small PNG with a script you keep in `e2e/fixtures/recipes/` (or inline base64 in the server), never a photo.
2. **Stub server:** `GET /recipes/<name>` serves `.html` and `.png` from that directory (regex like the ICS route, `text/html` and `image/png`).
3. **`e2e/m5.spec.ts`** (API):
   - import from both pages: `origin` jsonld and microdata, lines present;
   - `plain.html` with no LLM gives 503 `llm_unavailable`;
   - save; image stored (`GET …/image` 200, then 304 with the ETag);
   - the seed catalogue exists (`GET /ingredients` count > 200);
   - plan entries, two in one slot, swap;
   - template preview and apply with one slot in `add_slots`, then undo; `from-plan` and `duplicate`;
   - a store's own aisle order shows in `GET /grocery`;
   - generate twice (idempotent), staples section, reconcile after a delete;
   - authz: a child adds and checks, gets 403 on delete; the device adds without a PIN;
   - `GET /dashboard` carries `meals`.
4. **`apps/web/e2e/m5.spec.ts`** (UI, over the LAN address like the other specs):
   - an adult imports `jsonld.html` and saves;
   - adds it to tomorrow's dinner;
   - makes the list for the coming week and sees the items grouped;
   - applies a template over a free-text entry (Add) and sees both;
   - deletes a planned meal and answers the impact dialog;
   - a child checks an item;
   - offline: `context.setOffline(true)`, add and check, see `grocery-offline-note`, go back online, the note clears and the server has the items;
   - the kiosk Food view adds an item without a PIN, and the meals panel shows today's dinner.
5. **`ui-shots.routes`:** add `/food/plan`, `/food/list`, `/food/recipes`, a recipe page, `/food/templates`, `/settings/meals`, and the kiosk Food view.
