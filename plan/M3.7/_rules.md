# M3.7 ground rules

Read [`plan/_rules-common.md`](../_rules-common.md) first. These are the M3.7 deltas.

- **Contracts:** `plan/M3.7.md`, *Contracts fixed up front*, is the source of truth for names, types and wire formats shared between tasks.
- **Parallel tasks share `target/` and the dev DB.** Do not run `cargo sqlx prepare` (another task may be compiling; the `.sqlx` directory is shared). Use runtime `sqlx::query_as` / `sqlx::query` for every query you add or change, so `SQLX_OFFLINE=true` builds stay green without new `.sqlx` files. If you must change a `query!` macro, convert it to a runtime query.
- **Web checks** (from `apps/web`): `corepack pnpm@9 run typecheck`, `lint`, `test`. `apps/web/src/gen/**` is generated by the main session after wave 1; a web task in wave 1 that needs new DTO types hand-edits nothing in `gen/` and instead reports the types it expects, typing them locally with `as` casts that the main session removes after regeneration.
- **Local rustc is 1.99.1** and the workspace builds; `cargo test -p <crate>` and `cargo clippy -p <crate> --all-targets -- -D warnings` are what you run. Fresh Postgres port: 55400 + task number (T-02 → 55402).
- **Public AGPL repo (D-035):** no household specifics anywhere, fictional names in tests.
- **Read-only tasks** (T-05) write only their review file.
