## Work
1. **Setup shell `/setup` (§2a):**
   - The seven steps; resumable, back/next keeps values.
   - City search calls `https://geocoding-api.open-meteo.com/v1/search?name=<q>&count=5` from the browser (verified 2026-10-26), with lat/lon entry as the fallback.
   - The household step sends `base_url: location.origin`.
   - The master-key step asks for the password, shows Copy and Download (`family-assistant-master-key.txt`), and needs the tick before Next; it calls confirm.
   - Finish calls `POST /setup/complete`.
   - Router: on boot read `GET /setup`. `needed`/`owner_needed` sends every route to `/setup`, and so does an adult while `!completed`. Any `409 setup_required` from the API client goes to `/setup` too.
2. **Settings (§3c, U-08):**
   - A nested `/settings` route with `SettingsLayout` (sidebar on desktop, chips on mobile) and `SettingsIndexView` (groups Personal, Household, Sources and rules, System).
   - Existing settings pages become children.
   - **Members** moves to `/settings/members`, adult-only. Delete the `/members` route with **no redirect** (D-070).
   - **System:**
     - runtime settings from `GET /system/settings`, editable unless `locked` ("set by the server");
     - secrets are write-only fields;
     - after saving, show "applying…" and poll `/readyz`;
     - connection type stated as a fact;
     - the master-key backup warning until confirmed;
     - household file export (download) and import (upload, dry-run preview, then apply).
   - The `dashboard_pending_approvals` switch goes on the Household page.
   - **Personal:** the own-password form with the current password (C-03).
3. **Dashboard (D-068, D-078):**
   - delete `InboxPanel` and its registration; layouts naming `inbox` are ignored;
   - `AdvisoriesPanel` has no dismiss control;
   - `MembersPanel` shows a count-only badge per adult from `pending_approvals`;
   - nothing else from mail.
4. **Insecure context (D-072):**
   - Register the service worker only when `window.isSecureContext` (vite-plugin-pwa with manual registration).
   - Add `lib/ids` (a UUID without `crypto.randomUUID`) and `lib/copy` (clipboard with a textarea fallback); replace every `crypto.randomUUID`, `crypto.subtle` and `navigator.clipboard` use.
   - No not-encrypted banners anywhere.
   - Google shows "needs HTTPS (turn on Tailscale)" when not secure.
5. **U-09b to U-15:** do each as IMPROVEMENTS.md describes, within your paths.
6. Update and delete unit tests to match.
