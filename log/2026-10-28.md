# 2026-10-28

## First-start shakedown fixes
- Master key page: the copy now says the key is created automatically and that the field asks for the user's own login password (committed as `fab6e10`).
- Web client: a `202` with an empty body (queued calendar sync) made `res.json()` throw "Unexpected end of JSON input". `request` now reads the body as text and parses it only if non-empty.
- Calendar expansion: an `UNTIL` before `DTSTART` (a series cut off by a "this and following" edit) is now an empty series instead of an "unsupported recurrence rule" warning. Test and fixture `until_before_start.ics` added.
- Verification gap: the web dependencies were not installed in the session, so the web tests and type check did not run; the DB-backed `fa-calendar` ingest tests need Postgres and were not run. `scripts/ci-local.sh` still has to cover both.
