# 2026-11-28

## Weather effects and v0.1.41

- Snow only read the current weather code, so a snowy forecast with a non-snow reading (or any mismatch) showed nothing. It now uses the stronger of the current code and today's daily code. Added a rain layer (drizzle, rain, showers, thunder; snow wins) and a Christmas lights layer, with per-device switches `rain` (default on) and `christmas_lights` (default off) in `DashboardSettings` (Rust, OpenAPI, TS, layout editor).
- Released v0.1.41. Web lint, typecheck, test and build ran green. Not run: e2e, kiosk screenshots of the new effects (nobody has looked at them yet). Open: look at rain and lights on the kiosk; confirm the Release run time (`gh` is not installed).
