## Whiteboard: pen size popup and shapes
- The three width buttons collapsed into one pen button: tapping it selects the pen and opens a popup of sizes; picking one closes it. New shape tool (icon shows the current shape) with a popup of rectangle, circle, triangle and hexagon; drag corner to corner, outline only, using the current colour and pen size. Tapping without dragging draws nothing.
- Shapes are stored as `{s, p: [corner, corner]}` (old strokes load unchanged); the eraser now measures distance to the line segments, so it works on shapes and on fast freehand strokes. Popups are fixed-position beside the button (the toolbar scrolls and would clip them).
- Follow-up: line thickness is its own button (shows the current thickness, opens the size popup, does not change the tool) because it applies to shapes too; the pen button only selects the pen.
- Web lint, typecheck, test and build passed; not looked at in a browser. Not pushed or tagged.

## Dashboard clock an hour behind after Manitoba stopped changing clocks
- Cause: the dashboard clock formats with the browser's `Intl` and `America/Winnipeg`; the Echo Show's browser has old tz data and fell back today. Manitoba now keeps a fixed offset (the Echo stayed put). `chrono-tz` 0.10.4 (latest) bundles tz 2025b, so it lacks the change too; it only affects server-side event parsing.
- Updated all dependencies in range (`cargo update`, `pnpm update`): `scripts/ci-local.sh --no-web` and web lint, typecheck, test, build passed. Held back: typescript 7 (major), crates with newer majors or MSRV above 1.88 (`uuid`'s update took 1.29 in the lock; others unchanged). Disk filled mid-run: `cargo clean` (24.7 GB) fixed it.
- Still open: the dashboard clock itself. Options given: set the household zone to a fixed UTC-5 zone, or add a fixed-offset household setting. Waiting on the user's choice. e2e not run for the dependency bump (playwright 1.49 -> 1.64).
