## Dashboard: one refused completion hid every checkbox
- Cause: `store.complete()` turned any 403 into `completion_enabled: false` (household-wide read-only). A 403 is per task (its list is `adult_only`, `authz.rs` CompleteTask), so every Now checkbox vanished until the next refresh restored the setting; the task stayed because nothing was completed. Timestamps and the tz data were ruled out: the policy uses no clock.
- Fix (web only, no API change; the snapshot already carries each list's `completion_policy`): `taskLocked()` in `tasksModel.ts` locks a task when completion is off, its list is `adult_only` (unless the device is PIN-elevated), or the server refused it. A 403 now locks only that task and refetches. Panels Now, Member tasks and `TaskFlow` use it. Tests added; web lint, typecheck, test, build passed. Not looked at on the Echo.
- Open: the dashboard clock timezone choice (fixed UTC-5 zone or a fixed-offset setting); Echo fullscreen question raised by the user (answered in chat, not built).
