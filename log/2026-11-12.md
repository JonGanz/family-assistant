# 2026-11-12

## v0.1.27 routines fit in portrait
v0.1.27: kiosk portrait routines no longer run off the bottom. Cause: the cap was `max-height: 40dvh` only (dropped by kiosk browsers without dvh) and the band's row could grow past the screen. Fix in DashboardCanvas.vue: routines row `minmax(0, max-content)`, the band clips and its cards scroll inside (40vh then 40dvh). e2e m2 portrait test now adds a 6-step routine and checks 1080x1920 and 720x1280 that the routines card ends on screen. Checks: web lint 0 errors, typecheck OK, 754 tests, build OK; e2e 77 API + 45 UI passed.
Open: at 720px wide the weather card overflows its card sideways (seen in the screenshot, not fixed).

## v0.1.28 kiosk fits every screen
v0.1.28: kiosk fits every screen; tabs everywhere; tighter Month.
- Kiosk overflow analysis: the kiosk is drawn in rem at a 1920x1080 / 1080x1920 design size and the shell was `100vw x 100vh`. Screens with fewer CSS pixels (tablets, OS scaling, browser bars where 100vh is taller than the visible area) pushed the Week bar, Whiteboard tools and nav buttons off screen. Fix: `layouts/KioskLayout.vue` is fixed to the visible viewport (innerWidth x innerHeight, updated on resize/orientation/visualViewport) and sets the root font from `kiosk/fit.ts` (`kioskScale`: min(long/1920, short/1080), clamped 0.45..1), so the whole dashboard scales together.
- New e2e sweep in m2.spec.ts: every view (home, week, food, timers, whiteboard) at 1920x1080, 1366x768, 1280x720, 1024x600, 1080x1920, 800x1280, 600x1024; no button/field/tab/output outside the screen unless inside a scroller.
- Dashboard Week bar restyled like the menu (rounded layer-2 icon buttons with chevrons, bold label, pill switch); "Hide past events" is on by default.
- UiTabs is a tab row at every width (it was a segmented control on compact windows): Calendar, Inbox, Tasks, Food.
- Calendar Month: fixed 5.25rem week rows with 1rem one-line events (0.75rem text) instead of filling the viewport.
- Whiteboard swatches keep their round shape on narrow screens.
- Checks: web lint 0 errors, typecheck OK, 757 tests, build OK; ci-local OK; e2e 77 API + 46 UI passed.
Open: not verified on the household's actual kiosk device; scaling is not a per-device setting (could be added if a screen wants bigger or smaller text).
